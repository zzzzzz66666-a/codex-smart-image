已完成阶段：配置与加密凭据 → HTTP 和落盘幂等 → MCP/CLI → 自动发现 Skill → 隔离安装卸载 → 源码和 Skill 打包。

公开发布阶段（用户已授权）：

- [x] 公开包取消私人服务默认地址，首次使用必须本地配置。
- [x] 清理源码、测试、文档中的用户地址和本机信息。
- [x] 编写人用安装指南和 AI 安装 Skill。
- [x] 增加源码与 ZIP 隐私检查，限制发布文件类型。
- [x] 完整回归 42 项、独立代码与安装 Skill 场景审阅。
- [x] 开发 Skill 增加公开发布、双安装文档和交付目录验收流程。
- 发布执行：干净首次提交审计，核对公开 GitHub 仓库与 Release 的远端提交和附件摘要。
- 本地交付：复制双安装文档并核对 SHA256；将开发 Skill 更新同步回其原位置。

最后两项在发布执行环境单独记录，不把账户、交付目录和本机审计清单写入公开源码。仓库和 Release 是否可访问、附件摘要是否匹配，以实际远端回读为准。

测试先验证新行为缺失会失败，再实现。网络替身、配置、安装均使用临时隔离环境；真实服务验收不由替身结果代替。
